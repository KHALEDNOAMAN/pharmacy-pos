# Pharmacy+ POS User Manual

## Getting Started
1. Login with your staff credentials
2. Select your counter/terminal
3. The dashboard shows daily stats

## Processing a Sale
```
Search Drug → Add to Cart → Apply Discount → Payment → Print Receipt
```

## Key Features
| Feature | How to Access |
|---------|--------------|
| Drug Search | Type name or barcode |
| Patient History | Click patient name |
| Prescription | Upload or enter manually |
| Inventory | Menu → Inventory |
| Reports | Menu → Reports → Daily/Monthly |

## Drug Interactions Warning
The system automatically flags:
- Contraindicated combinations
- Dosage warnings
- Allergy alerts (if patient profile exists)

## End of Day
1. Print daily summary
2. Verify cash count
3. Run inventory check
4. Log out
